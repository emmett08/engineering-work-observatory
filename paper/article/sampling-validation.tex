Comparing a prediction with sampled labour combines prediction error with sampling error. Use labour recorded for teams or periods excluded when fitting the prediction rule, keeping predictions unchanged whichever validation sample is drawn. The following calculations separate prediction error against true labour from sampling variance.

Treat each task's labour $H$ in a finite validation population as fixed. Let $f$ be its prediction, calculated before validation sampling and unchanged whichever sample is drawn, and suppose $\E_{\!s}[\widehat H]=H$ with finite design variance. Then
\begin{align*}
 \E_{\!s}[f-\widehat H]&=f-H,\\
 \E_{\!s}[(f-\widehat H)^2]&=(f-H)^2+\Var_{\!s}(\widehat H).
\end{align*}
Expanding the squared difference proves the second identity because the cross term has expectation zero when $\E_{\!s}[\widehat H-H]=0$. The signed comparison therefore recovers prediction error on average, while the squared comparison also includes sampling variance. These identities hold for each task under the sampling design used to select its observed intervals. Aggregate uncertainty additionally depends on covariances between tasks' estimates.

For a second prediction $g$ calculated before the same validation sample and unchanged whichever sample is drawn, subtracting the expected squared errors cancels the common sampling variance, giving
\[
 \E_{\!s}[(f-\widehat H)^2-(g-\widehat H)^2]
 =(f-H)^2-(g-H)^2.
\]
Over repeated validation samples, the average difference between the two squared prediction errors equals their difference calculated against true labour. Estimating either predictor's squared error against true labour, or quantifying sampling uncertainty in their comparison, requires further sampling-design information.

The squared-error cancellation leaves open how sampling noise affects absolute error and interval coverage. To examine these measures, consider eight one-hour person-intervals with allocations $(1,1,1,1,0,0,0,0)$. Sample one uniformly, with inclusion probability $1/8$. True labour is $H=4$, whereas its Horvitz--Thompson estimate is $0$ or $8$, each with probability $1/2$. A perfect prediction $f=4$ consequently has apparent absolute error $4$ against the sampled estimate. The interval $[3.5,4.5]$ always contains true labour but never contains the sampled estimate. Both apparent failures arise from comparing an accurate prediction or interval with a noisy labour estimate. The signed difference between prediction and sampled estimate remains unbiased for the prediction's error against true labour. Absolute error and interval coverage calculated against $\widehat H$ measure agreement with the sampled estimate, including its sampling error.

Prediction validation must therefore distinguish the prediction's error from uncertainty in the labour measurements. One way to obtain task-level reference measurements is to record allocations for every person-interval in each target window for a validation subset of tasks. Independently check those records, identifying the reviewers and evidence used to resolve discrepancies. State how checking remains independent of recording, and report remaining measurement error. Alternatively, use a measurement model under which the observations uniquely determine the chosen accuracy measure. Retain inclusion probabilities and joint sampling-design information for uncertainty calculations. Report systematic overstatement or understatement and the size of individual prediction errors by study group, type of work and explicitly defined task category. Correlation between group averages alone leaves systematic prediction bias and individual prediction errors unresolved.

The same validation must establish what the output scores represent, so prediction accuracy can be interpreted alongside the work delivered. Test whether task splitting, code-change squashing or changes to the task information supplied to the scoring rule alter the reference score. Report reviewer disagreement and follow-up completeness alongside prediction error. Recalculate comparisons between study groups using plausible amounts of missing labour and disputed retained-output scores. If plausible measurement errors reverse which group has the better outcome, the choice between AI tools and working practices depends on how that uncertainty is resolved or accepted.
