A sampled labour estimate can differ from true labour, so its difference from a prediction includes sampling error. Compare frozen telemetry predictions by assigned intervention, role and task class on held-out teams or periods, while accounting for that sampling error. Correlation between group averages does not establish whether predictions systematically overstate or understate labour, or how far individual predictions are from true labour. The following calculations separate prediction error against true labour from sampling variance.

Treat each task's labour $H$ in a finite validation population as fixed. Let $f$ be its prediction, frozen before validation sampling, and suppose $\E_{\!s}[\widehat H]=H$ with finite design variance. Then
\begin{align*}
 \E_{\!s}[f-\widehat H]&=f-H,\\
 \E_{\!s}[(f-\widehat H)^2]&=(f-H)^2+\Var_{\!s}(\widehat H).
\end{align*}
Expand the square: the cross term vanishes because $\E_{\!s}[\widehat H-H]=0$. These identities hold for each task under its stated sampling design. Aggregate uncertainty additionally depends on covariances between tasks' estimates.

For a second prediction $g$ frozen before the same validation sample, subtraction cancels the common sampling variance:
\[
 \E_{\!s}[(f-\widehat H)^2-(g-\widehat H)^2]
 =(f-H)^2-(g-H)^2.
\]
Over repeated validation samples, the average difference between the two squared prediction errors equals their difference calculated against true labour. Estimating either predictor's squared error against true labour, or quantifying sampling uncertainty in their comparison, requires further sampling-design information. Absolute error requires a separate analysis.

For example, eight one-hour person-intervals have allocations $(1,1,1,1,0,0,0,0)$. Sample one uniformly, with inclusion probability $1/8$. True labour is $H=4$, whereas its HT estimate is $0$ or $8$, each with probability $1/2$. A perfect prediction $f=4$ has apparent absolute error $4$ against the sampled estimate. The interval $[3.5,4.5]$ always contains true labour but never contains the sampled estimate. The signed difference between prediction and sampled estimate remains unbiased for the prediction's error against true labour. Absolute error and interval coverage calculated against $\widehat H$ measure agreement with the sampled estimate, including its sampling error.

To assess accuracy against true labour, select a validation subset of tasks, record allocations for every person-interval in each task's target window, and adjudicate the records independently. Report remaining measurement error. Alternatively, specify a measurement model under which the observations uniquely determine the chosen measure of prediction accuracy. Retain inclusion probabilities and joint sampling-design information for uncertainty calculations.

Validation should also test whether task splitting, code-change squashing or changes to the task representation alter the reference score. Report reviewer disagreement and follow-up completeness alongside prediction error. Recalculate intervention comparisons using plausible amounts of missing labour and disputed retention scores. If these changes reverse which intervention ranks higher, choosing an intervention requires resolving or accepting the measurement uncertainty.
