What does a difference between predicted labour and a sample-based labour estimate tell us? It reflects prediction error together with variation caused by which intervals were selected. To evaluate predictions on work outside the training data, use teams or periods excluded from training. Calculate predictions before selecting the validation intervals and keep them unchanged whichever sample is selected. Under these conditions, the following calculations distinguish error against true labour from variation due to sampling.

Treat each task's labour $H$ in a finite set of validation tasks as fixed. Let $f$ be its prediction, calculated before validation sampling and unchanged whichever sample is drawn, and suppose $\E_{\!s}[\widehat H]=H$ with finite sampling variance. Then
\begin{align*}
 \E_{\!s}[f-\widehat H]&=f-H,\\
 \E_{\!s}[(f-\widehat H)^2]&=(f-H)^2+\Var_{\!s}(\widehat H).
\end{align*}
Expanding the squared difference proves the second identity because the cross term has expectation zero when $\E_{\!s}[\widehat H-H]=0$. Averaging the signed difference over repeated samples therefore gives the prediction's error against true labour. Averaging its square gives squared prediction error plus sampling variance. These identities hold for each task under the sampling design used to select its observed intervals. Uncertainty in results combined across tasks also depends on how their labour estimates vary together.

For a second prediction $g$ calculated before the same validation sample and unchanged whichever sample is drawn, subtracting the expected squared errors cancels the common sampling variance, giving
\[
 \E_{\!s}[(f-\widehat H)^2-(g-\widehat H)^2]
 =(f-H)^2-(g-H)^2.
\]
Over repeated validation samples, the average difference between the two squared prediction errors equals their difference calculated against true labour. Estimating either predictor's squared error against true labour, or quantifying sampling uncertainty in their comparison, requires further sampling-design information.

Absolute prediction error and coverage of prediction intervals need a separate check because the squared-error calculation does not justify them. To examine these measures, consider eight one-hour person-intervals with allocations $(1,1,1,1,0,0,0,0)$. Sample one uniformly, with inclusion probability $1/8$. True labour is $H=4$, whereas its Horvitz--Thompson estimate is $0$ or $8$, each with probability $1/2$. A prediction equal to true labour, $f=4$, therefore differs from either sampled estimate by $4$. The prediction interval $[3.5,4.5]$ always contains true labour but never contains the sampled estimate. Here the discrepancy comes entirely from sampling error in the labour estimate. The signed difference between prediction and sampled estimate remains unbiased for the prediction's error against true labour. Absolute errors and prediction-interval coverage judged against $\widehat H$ measure agreement with the sampled estimate, including its sampling error.

Prediction validation must distinguish prediction error from uncertainty in the labour measurements. One option is to select tasks for validation and measure labour in every person-interval within the periods being evaluated. Check those measurements independently, stating who reviewed them, which evidence resolved discrepancies and how the review was independent of the people who supplied the observations. Report any remaining measurement error. Alternatively, use an explicit model of the measurements under which the available observations uniquely determine the chosen accuracy measure. Keep the probabilities of selecting intervals singly and together so uncertainty can be calculated. Report systematic overstatement or understatement and individual prediction errors by study group, type of work and defined task category. Report these individual errors alongside any correlation between predicted and observed group means.

Validate the output scores as well, so prediction accuracy can be assessed alongside how much of the accepted requirement remains satisfied. Check whether splitting a task, squashing code changes or changing the scoring inputs changes its reference score. Report how often reviewers disagree and how many scheduled follow-up assessments were completed, alongside prediction error. Recalculate group comparisons using plausible amounts of missing labour and disputed output scores. If those measurement errors change which group performs better, choosing between tools and working practices requires resolving or explicitly accepting that uncertainty.
