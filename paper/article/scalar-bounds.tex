\section{A shortest-path solution for one allocation stream}
\label{app:scalar}

For one person performing one type of work on a single task, write $0\leq a\leq1$ for the allocation function. At each calendar boundary in Section~\ref{sec:sharp-identification}, cumulative labour equals $z_k=\int_{b_0}^{b_k}a(t)\,dt$. Each observation limits a difference between two such totals. Represent an upper bound $z_q-z_p\leq w$ by a directed edge $p\to q$ of weight $w$ \cite[Slides~6--11]{indyk2011}.

Cell $k$ can contain at most $d_k$ person-hours, giving the edge $k-1\to k$ of weight $d_k$. Labour is nonnegative, so cumulative hours cannot decrease, giving a reverse edge of weight zero. In the same way, observed limits $[v^-,v^+]$ on labour between $b_p$ and $b_q$ give edge $p\to q$ weight $v^+$ and edge $q\to p$ weight $-v^-$. An exact total $v$ gives weights $v$ and $-v$.

Adding the inequalities along a path cancels its intermediate cumulative totals. The path weight therefore bounds the difference between the totals at its endpoints. The shortest path from $p$ to $q$ gives the tightest upper limit. A path from $q$ to $p$ bounds $z_p-z_q$, so negating the shortest return distance gives the lower limit on $z_q-z_p$.

\begin{proposition}[Attainable cumulative bounds from graph distances]
\label{prop:graph-bounds}
The observations for this single allocation function admit an allocation if and only if this graph has no directed cycle of negative total weight. When such an allocation exists, let $D(p,q)$ be the shortest-path weight from $p$ to $q$. For any endpoint pair $p\leq q$, the identified range of $\int_{b_p}^{b_q}a(t)\,dt$ is
\begin{equation}
\label{eq:graph-range}
 [-D(q,p),\;D(p,q)].
\end{equation}
\end{proposition}
\begin{proof}
The cumulative differences sum to zero around a cycle. Their sum cannot satisfy an upper bound below zero, so any feasible graph must have nonnegative weight around every directed cycle. For the converse, suppose the graph contains no negative cycle. The adjacent edges connect every pair of vertices in both directions, so all shortest-path weights are finite and $D(r,r)=0$. Fix a starting vertex $r$. Each edge $u\to v$ of weight $w$ satisfies $D(r,v)\leq D(r,u)+w$, so the values $z_k=D(r,k)$ obey every inequality. Subtracting $z_0$ from all values makes initial labour zero and preserves their differences. Since $0\leq z_k-z_{k-1}\leq d_k$, a constant allocation of $(z_k-z_{k-1})/d_k$ in each cell realises the proposed cumulative totals.

The forward and return path inequalities give $-D(q,p)\leq z_q-z_p\leq D(p,q)$. Choosing $r=p$ attains the upper limit and choosing $r=q$ attains the lower limit. Convex combinations of these two schedules attain all values between them.
\end{proof}

The reference implementation computes all pairwise distances in exact rational arithmetic. With sorted, indexed boundaries, constructing the graph and computing its distances takes $O((K+1)^3+M)$ arithmetic operations and $O((K+1)^2+M)$ storage, where $K+1$ is the number of time boundaries and $M$ the number of observations. The bit cost of each operation depends on the sizes of its rational operands. An independent enumeration checks the endpoints and schedules in finite examples with overlapping intervals. It also checks that the calculation detects inconsistent observations.

Separate graphs for several tasks can allow one person to exceed their available time. Proposition~\ref{prop:cell-reduction} enforces a single time limit across that person's activities. Both methods require observations identifying the people and activities covered in each interval.
