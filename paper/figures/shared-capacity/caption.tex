\textbf{One person divides two hours between two tasks.}
Each task takes one person-hour in total.
In (a), $x$ and $y$ give each task's first-hour labour. Considering each task separately permits any point in the square. The tasks fill both hours, so the possible pairs lie on the diagonal.
Panel (b) shows the consequence for the first hour. Adding the separate bounds gives a range from zero to two person-hours. The person's capacity in both hours fixes the sum at one.
Panel (c) shows one schedule for $P=(0.5,0.5)$. The person spends half of each hour on each task. Other schedules are possible because the example allows switching at any time.
